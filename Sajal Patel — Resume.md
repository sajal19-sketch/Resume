Aug 2026MV3

### Ontario Parks Campground Monitor

A Google Chrome extension on the Manifest V3 architecture that monitors high-demand campsites such as Killbear Provincial Park, so nobody has to refresh the page by hand.

JavaScriptManifest V3Content scriptsDOM parsing

[View on GitHub](https://github.com/sajal19-sketch/ontario-parks-extension)

1. **Watch**JavaScript content scripts keep reading the reservation site’s DOM for real-time updates.
2. **Detect**The moment a campsite opens up, the extension spots the vacancy.
3. **Alert**A custom audio alert fires right away, which speeds up the booking process.
