A glassy bar that drops down from the MacBook notch, plus Dangle: a little Claude Code companion that hangs from the notch, shows what the AI agent is doing, and lets you approve its requests without touching the terminal.

Built with Swift and SwiftUI

I built it with Claude Code as my pair programmer. Hangtime hooks into Claude Code over 127.0.0.1 with a random token. If the app isn't running, Claude Code works exactly as normal.

Cooling LLM

Data centers use huge amounts of water to stay cool. I turned a local LLM into a cooling-systems inventor that learns real systems, prototypes and water-shortage data, then keeps generating and testing ideas until it finds a zero-water approach that doesn't exist yet. No cloud GPUs: it runs on my own laptop, all night.
